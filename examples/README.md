# Exemplos

Esta pasta descreve cenários de teste sem armazenar imagens pessoais.

## Imagem → Imagem

- Forneça duas imagens de páginas originais.
- Forneça um PDF com várias amostras de caligrafia.
- Verifique a transcrição antes de confirmar.
- Gere e compare cada página separadamente.

## Texto → Imagem

- Cole um texto com título, lista e fórmula.
- Forneça o PDF de referência.
- Escolha uma página ou distribuição em várias páginas.
- Revise o conteúdo e gere após confirmar.

Use dados fictícios ou imagens para as quais você tenha autorização. Não inclua escrita pessoal de terceiros no repositório.
